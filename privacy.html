Política de Privacidade — Genie

Última atualização: 16/11/2026

O Genie é um aplicativo de uso pessoal que roda localmente no computador do seu proprietário. Ele usa os Serviços de API do YouTube.

Dados acessados

Com a autorização do usuário via Google OAuth, o Genie acessa: envio e edição de vídeos, thumbnails e metadados no canal autorizado (YouTube Data API) e relatórios de desempenho e receita estimada do canal (YouTube Analytics API).

Uso e armazenamento

Os dados são usados apenas para publicar/agendar vídeos e exibir métricas ao próprio usuário. Tokens de acesso e dados ficam armazenados somente no computador do usuário. Nada é vendido, compartilhado com terceiros ou enviado a servidores do desenvolvedor.

Revogação e exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Apagar a pasta de configuração do Genie remove todos os dados locais.

O Genie usa os Serviços de API do YouTube; ao usá-lo você concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
